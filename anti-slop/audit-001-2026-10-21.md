# Antislop audit — README comparison image

Date: 2026-10-21
Scope: `docs/images/why-nimbang.svg` and its README context.

## Findings

### 1. The illustration is in Indonesian while the README is in English — MEDIUM (R-16)

The labels and example text in `docs/images/why-nimbang.svg` are Indonesian, which makes this English-language README comparison difficult to follow.

### 2. The illustration shows a partial comparison, not the end-to-end framework — MEDIUM (R-05)

The graphic contrasts a pros/cons list with a score result. It omits the nine-stage path (Frame through Commit), even though the README introduces the complete pipeline immediately above.

### 3. The example uses precise, unsupported claims — HIGH (R-17, R-38)

The SVG gives a `0.04` margin and claims a single input flips the ranking, but the README provides no example data or source to support those values. Remove these specifics or clearly ground them in a documented example.

### 4. The figure's detail and explanatory copy can be simplified — LOW (R-16)

The graphic currently carries several lines of scenario-specific text. A concise sequence of stage names and plain-language labels would better match the request for a simple explanation.

## Proposed changes

- Replace the comparison graphic with a simple English, left-to-right view of all nine framework stages, grouped into a few readable phases and using short plain-language captions.
- Avoid invented scores, scenario details, and claims about what reverses a result.
- Update the README image alt text to describe the full pipeline accessibly.
- Keep the existing README paragraph about why a weighted comparison is useful unless the replacement figure makes a small wording adjustment necessary.
